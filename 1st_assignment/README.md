# chapter_2025
This repository contains the cutting data and analysis files used in the Chpater X of the Book [Ref], focusing on turning operations with coated carbide tools. 
The dataset illustrates the impact of maintaining constant Material Removal Rate (MRR) during the diameter reduction of steel parts while using optimal cutting parameters recommended by the tool manufacturer.

# Assignment instructions

In this assignment you have to:

1) Uses the parameters available in the chapter for the smaller granite to predict the cutting power in turning

2) Using the total power recorded and presented in the GitHub, compare the timings with your prediction and claim your conclusions about the curve profile

3) Do your own code in python to Calculate the Specific Cutting Pressure

For that, you should identify the power for cutting during steady state and the power for the spindle without cutting

4) Using this specific cutting pressure and cutting speed (of the smaller diameter in turning at constant spindle speed), predict the curve of the following drilling process :

  - pre-Drilling with 5 mm diameter, 120 degrees point angle, machining length 10 mm, feed per revolution 0,2 mm
